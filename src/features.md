# ![](/favicon.svg) Slide<span class="st-take">take</span> Features

Every feature, and what it saves you. Press → to walk them, **O** for the map, or read how each works in the [docs](/docs).

## ✂️ Recording without timeline editing

The reason Slidetake exists: a talk you record comes out finished.

| Feature | Advantage |
|---|---|
| **Every slide is a take** | a fumbled line costs one press (←), not an editing session |
| **OBS driven by the deck** | broadcast-quality video with no scenes to switch or recording to babysit |
| **Pick the best take per slide** | choose, don't scrub; every attempt is kept |
| **Frame-exact ffmpeg cut** | the finished video is one command, no editor needed |
| **YouTube chapters and description** | the publish pack is written from your deck |
| **Pause and resume** (B) | step away mid-recording without a gap to cut |

## 🗺️ A spatial deck

| Feature | Advantage |
|---|---|
| **Headings become cards** | the structure of your talk is its layout; nothing to draw |
| **Four layouts**: focus, path, radial, tree | a map to explain systems, a staircase for video, or one slide at a time |
| **The map** (O) and **map moments** | show the whole picture before diving in, and the audience never gets lost |
| **Steady text** | text keeps its size within a section, so slides don't jump |
| **Smooth camera moves** | each step is a short, readable flight, made for video |

## 🎥 The camera, scripted

| Feature | Advantage |
|---|---|
| **Webcam in the deck** | you and the slides in one recording, no compositing |
| **Camera per slide** | a comment moves you: corner, full screen, off |
| **Several steps per slide** | open on you, then reveal the slide, in one take |
| **Full-screen cards** keep the camera off | big images get the whole screen |
| **V** to change layout live | adjust mid-talk without editing the deck |

## ✍️ Plain markdown in

| Feature | Advantage |
|---|---|
| **Ordinary markdown** | write in any editor, version in git, diff and review like code |
| **Steps** (`<!-- steps -->`) | reveal a list one item per press |
| **Diagrams**: Graphviz, D2, SVG | diagrams as text, in the deck's colours |
| **Charts**: ECharts | real charts from JSON, redrawn for dark and light |
| **Image cards, galleries, carousels** | screenshots laid out by their shape, no positioning |
| **YouTube links** | the video plays on the next press |
| **reveal.js and `+++` decks** | existing decks open as they are |

## 🎨 Yours to theme

| Feature | Advantage |
|---|---|
| **Dark and light** | follows the reader, or your site |
| **`accent:` per deck** | one colour, shaded for both modes automatically |
| **Site colours for embeds** | decks wear your site's palette and header |
| **Brand and logo** | your name on every frame of the video |

## 🧭 Four ways to run it

| Way | Advantage |
|---|---|
| **slidetake.com** | open any deck from a GitHub link, gist or URL, or type one; nothing to install |
| **npx slidetake** | your files and images, offline, reloading as you save, and edits in the browser save back to the file |
| **slidetake.js on your site** | decks inside your own pages; the hugo-continuum theme does it with one frontmatter key |
| **With AI** | any AI writes the markdown; an agent writes the file and `npx slidetake` shows it as it changes |

## 🔒 Private and open

| Feature | Advantage |
|---|---|
| **No accounts, no stored decks** | nothing to sign up for or lose; everything that leaves the browser is listed on the [privacy page](/privacy) |
| **Decks inside links** | share without uploading; the deck stays in the `#` part of the address |
| **Your copy in your browser** | edit any deck freely; the original never changes |
| **Open source, Apache 2.0** | read it, host it, change it: [github.com/slidetake/slidetake](https://github.com/slidetake/slidetake) |
