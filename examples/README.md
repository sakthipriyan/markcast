# Examples

Decks to look at, start from, and test Slidetake with. Each is plain markdown.

| Deck | What it is | Open it |
|---|---|---|
| [showcase.md](showcase.md) | Everything a deck can hold: text, steps, tables, code, Graphviz, D2, SVG, ECharts, images, galleries, YouTube, camera | [slidetake.com/showcase](https://slidetake.com/showcase) |
| [blank.md](blank.md) | Starter: a first card, a section and a detail | [/new?template=blank](https://slidetake.com/new?template=blank) |
| [talk.md](talk.md) | Starter: why it matters, the idea, trade-offs, summary | [/new?template=talk](https://slidetake.com/new?template=talk) |
| [recording.md](recording.md) | Starter for a video: camera steps, an overview moment, a closing on camera | [/new?template=recording](https://slidetake.com/new?template=recording) |
| [why-debt-is-not-bad.md](why-debt-is-not-bad.md) | A real talk, in the headings format | [open](https://slidetake.com/gh/slidetake/slidetake/examples/why-debt-is-not-bad.md) |
| [embed.html](embed.html) | How a website hosts a deck with `slidetake.js` | |

To start from one: open it on slidetake.com and type, and it becomes your own copy. Or copy the file into your own repository and open it with `slidetake.com/gh/you/repo/deck.md`.

The showcase and templates are built into Slidetake, so these files are also what slidetake.com serves at `/showcase` and `/new`.
